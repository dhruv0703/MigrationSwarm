# Changelog

All notable changes to MigrationSwarm are documented here. This project follows
an experimental release-candidate cadence and makes no production-readiness
claim.

## 0.1.0

- Added deterministic repository inventory, Java dependency, and architecture analysis.
- Added grounded service-boundary reasoning and migration planning.
- Added provider-neutral model routing for Groq and SiliconFlow.
- Added task DAG scheduling and durable task lifecycle persistence.
- Added managed Git worktree isolation for code-changing tasks.
- Added copy-first service extraction and deterministic build verification.
- Added bounded worker and verification-worker paths.
- Added explicit DEBUG repair tasks with finite attempts.
- Added single-service and multi-service migration orchestration.
- Added explicit service approvals and failure isolation.
- Added PostgreSQL durable state and Redis transient coordination contracts.
- Added security hardening for paths, symlinks, secrets, subprocesses, and artifacts.
- Added benchmark, observability, recovery, and performance characterization.
- Added typed semantic behavior contracts with allowlisted normalization.
- Added packaging, clean-install, and bounded release-candidate validation.
